# WEAKNESSES.md 格式

`practice/<階段>/WEAKNESSES.md` 記錄使用者在這個階段卡過、投降過、被糾正過的地方。代理展開新練習前讀它，挑「待重做」的項目出變化題當暖身。第一次需要記錄時才建立。

## 範本

```md
# <階段代號> 弱點紀錄

## W-001 <短標題>
- 日期：YYYY-MM-DD
- 類型：卡住／投降／錯誤觀念
- 內容：<一到三句：卡在哪、正確理解是什麼>
- 重做：待重做（或「已重做通過 YYYY-MM-DD，練習 NN」）
```

## 規則

- **編號跨整份檔案遞增**：找最大的 `W-` 編號加一。
- **只記三種類型**：
  - 卡住：靠提示才解開。
  - 投降：使用者說投降後才拿到答案。
  - 錯誤觀念：使用者原本相信錯的東西，現在知道為什麼錯。
- **不記流水帳**。只看過、只做過、一次就做對的內容，不記。
- **重做用變化題**：換數值、換情境或反過來問，不是原題重出。重做通過後，更新「重做」欄，不刪除項目。
- **重做沒通過**：「重做」欄維持「待重做」，在「內容」補一句這次錯在哪。
